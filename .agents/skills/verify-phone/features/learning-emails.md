# Learning emails

The switch for learning emails on the You tab, which web Settings and an email's unsubscribe link change too.

## Reach

The **You** tab, in the rows under the reminder.

## Drive

[`learning-emails.yaml`](learning-emails.yaml) turns the switch off.

## End state

`/api/settings` answers `learningEmails: false`.

## Gotchas

The sign-in screen's line about emails is on Welcome, which [welcome.md](welcome.md) reaches.

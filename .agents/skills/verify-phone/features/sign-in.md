# Sign in with Apple

The signed-out screen offers Apple’s native Continue with Apple button only where `isAvailableAsync()` succeeds. The phone sends a fresh nonce’s hash to Apple and its raw value with the signed token to Better Auth. A cancelled sheet leaves the learner at the door without an error; a failure leaves a retry. The first name Apple supplies is kept, and SecureStore keeps the session across relaunches.

The Simulator recipe proves the signed-out control is present in an Apple-capable development binary. It does not complete Apple account authentication. A physical iPhone must separately verify first sign-in with a shared address and Hide My Email, cancellation, relaunch and repeat sign-in, and deletion confirmed with Apple. Deletion must revoke the app’s grant when the signing key is configured. Web and native must open the same account when they use the grouped App ID and Services ID.

# Original product brief

The initial brief described a private vocabulary app for one person. That scope is obsolete. Lymi is now a flashcard app for learning any subject, with public sign-up, shared and published decks, and web, phone and Mac apps.

Use [PRODUCT.md](../PRODUCT.md) for positioning and scope, [CONTEXT.md](../CONTEXT.md) for product terms, and [DESIGN.md](../DESIGN.md) for interface rules. The original brief remains available in Git history.

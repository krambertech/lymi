# Review completion

A review ends on a dedicated screen with the lantern, a heading describing the outcome, today’s review count, the seven-day display, the streak and the available actions. Closing review with X also opens it after at least one grade since the previous completion screen. [ADR 0021](../adr/0021-a-review-runs-to-its-end-and-stops-once-at-the-goal.md) defines the ending rules.

Every way on is the same full-width button, and each keeps its place on every end: Review forgotten first, then Continue, then Done, always last and always primary, so leaving is always in the same place. Continue never names a deck, so a long name never stretches it; beside its label, in quiet text and centred with it, it says what it holds: how many reviews reach the goal ("Continue 21 to goal") where the day's review stops there, the cards left in cards ("8 cards left"), because a forgotten card's return adds a review but not a card, or "other decks" when a deck ran out and Continue moves on. It shows no count it cannot stand behind: none for a round, and none while the other decks are not known. While the goal is open the large number reads against it, "4 of 25 reviews today", so the count beside Continue explains itself. Review forgotten says how many cards it holds in words, "Review 3 forgotten cards", because a number in a pill reads as a keyboard shortcut; it appears only when it holds something. With nothing due, Add cards sits above Done.

Embers lift off the flame on every end that added reviews, more for more work, and the pool glows at full strength; an end that added nothing keeps the pool at half. Only when the day has just turned, a spark carries it from the flame into today's light, which fills and throws a few flecks, and on to the run's flame, which catches as the run rolls up by one; on the phone it is felt as a tick, a tap and a warm pulse. [motion.md](system/motion.md#the-end-of-a-review) has the timings. Running out of cards offline or after a failed refresh is not an end: the screen says it couldn't check for more and offers Try again.

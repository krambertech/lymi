# Review completion

A review ends on its own screen, not a copy of Today: no plates, the lantern lit large in a pool of its glow, the heading from what ended, today's count as the largest thing on the screen, the week's lights at Today's size with the run under them, then the ways on. X ends on this screen too, once something was graded since the last one; [ADR 0021](../adr/0021-a-review-runs-to-its-end-and-stops-once-at-the-goal.md) has the rules for every ending.

Every way on is the same full-width button, and the primary one sits last, where the thumb is. While the day is open and there is more to review, Continue is primary, Done sits above it, and a quiet line under the lights says how many more reviews reach the goal, or how many cards finish the day. Once the day is satisfied, Done is primary and Continue is secondary above it. Review forgotten says how many cards it holds in words, “Review 3 forgotten cards”, because a number in a pill reads as a keyboard shortcut; it appears only when it holds something. Continue carries no count, because what is left moves as forgotten cards return. With nothing due, Add cards is primary and Done sits under it.

Embers lift off the flame on every end that added reviews, more for more work, and the pool glows at full strength; an end that added nothing keeps the pool at half. Today's light flares and the run ticks only when the day just turned. Running out of cards offline or after a failed refresh is not an end: the screen says it couldn't check for more and offers Try again.
